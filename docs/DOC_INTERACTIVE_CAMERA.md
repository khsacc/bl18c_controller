# Interactive Camera

> [!Notes]
> ここではアプリケーションの使用方法に特化して説明します。オートフォーカスおよび自動追従に用いている画像認識技術の詳細については、別立てドキュメント [Interactive camera で用いられている画像認識手法](./DOC_SUB_CAMERA_CV2.md) を参照してください。

## Experimental Scheduler 実行中

ランチャーから起動した場合、顕微鏡カメラへの接続はアプリケーション起動時に始まり、
Interactive Camera、Experimental Scheduler、Run Monitor が同じライブ映像を使用します。
シーケンス開始時に Interactive Camera が開いていれば、ウィンドウはそのまま残り、
ライブ映像だけを表示する画面に切り替わります。操作メニューやステージ移動、撮影、
追従、オートフォーカスは使用できず、シーケンス終了後に元の画面へ戻ります。

録画、追従、オートフォーカス、手動のステージ移動が進行中の場合は、
それらを終了するまでシーケンスを開始できません。シーケンス中に初めて
Interactive Camera を開いた場合も、閲覧専用のライブ画面が表示されます。
