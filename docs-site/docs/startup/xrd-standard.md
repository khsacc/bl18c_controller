# XRD 測定準備

基本的には、従来の実験で行っていた立ち上げと同じですが、自動実験のためには、以下の追加操作が必要です。

* X線位置は、テレビ画面上にペンでマークするのに加えて、Interactive Camera上で登録する必要があります。これは、ガスケットのEdge検出による試料追従に必要です。
* 自動化プラットフォームからの即時1次元化を行うためには、IPAnalyzerではなく、アプリ内でも較正を行う必要があります（較正に使うCeO<sub>2</sub>データ自体は共通で構いません）。

## 1. コリメータスキャン

- コリメータを設置し、コリメータスキャンを行います。

## 2. DAC スキャン

- おおよその試料位置にDACを置き、顕微鏡で位置を観察して固定します。
- DACスキャンを実施します。
