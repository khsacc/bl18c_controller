# 5. 分光測定準備

オンライン分光器のセットアップをします。

## 1. 波長較正 @ FluoRaPressée 

- オンライン分光器の制御PCにリモート接続し、 FluoRaPressée を開きます。FluoRaPressée の較正機能を用いて横軸を較正しておきます。

## 2. レーザー位置登録

- レーザーをONにし、ルビーなどレーザー位置がわかりやすい試料に当てます。
- その状態で、 **Interactive Camera**を開きます。レーザーの位置で右クリックし、 **Remember this position as laser spot position**とします。これで、レーザー位置に対応するカメラ上のピクセル位置を記憶できました。
