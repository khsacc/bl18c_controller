# Interactive Camera の較正

画像上の1 pxが、実際には何ミクロンに対応するのかを決めるとともに、カメラの傾きを補正するために較正を行います。
カメラを取り外さなければ較正は変わらないはずですが、実際には、時間があくと少し変化していることが多いです。
Interactive Cameraの動作は自動測定においても非常に重要であるため、自動測定を計画しているBTでは、最初に較正することをお勧めします。

## 手順

Ch4とCh5の移動量をステージパルス数から読み取りながら、画像上でも対応づけることで較正します。


0. 何かしら、位置標準となる試料を置き、顕微鏡のフォーカスを合わせます。DAC背面のゴミや、アルミの板などが良いです。ダイヤ越しに見た試料は、標準試料としてはお勧めしません。
1. Interactive Camera の **Settings → Calibration…** を開きます。
2. 画面上で、目印となる場所を決めます。できるだけ画面の端に目印を置いてください。**Record Origin Motor Position** を押したあと、カメラ画像上で、目印として決めた場所をクリックします。
3. **Ch4 だけ**をできるだけ大きく動かし、**Record Ch4-Moved Position** を押したあと、移動した目印の位置を画像上でクリックします。
4. **Ch5 だけ**をできるだけ大きく動かし、**Record Ch5-Moved Position** を押したあと、移動した目印の位置を画像上でクリックします。
5. **Calculate Calibration** を押します。ダイアログを閉じると、較正結果が保存・適用されます。

各段階で、モーター位置を記録してから画像をクリックしてください。
