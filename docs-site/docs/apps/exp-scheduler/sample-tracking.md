# 試料追従の設定

## Interactive Camera の設定を引き継ぐ

Interactive Camera の **Sample Tracking (Gasket Detection)** タブで準備したガスケット追従の設定は、**Sample Positions** パネルの **Import from Interactive Camera** で引き継げます。**Set up sample positions…** の隣にあります。

引き継ぐもの：

- 参照写真、ガスケットの輪郭（楕円）、試料位置（ガスケット中心または指定した点）、参照写真を撮影したときの Ch3/Ch4/Ch5
- ルビー位置（ガスケット中心からのオフセット）
- **Gasket tolerance**、**Average frames**、**Allow uniform ellipse scaling** の値

押すと確認の後、現在の参照写真・輪郭・試料位置・ルビー位置が置き換わり、**Position tracking** が **Gasket outline (Beta)** になります。シーケンス実行中は使えません。Interactive Camera 側で参照写真がない、輪郭が別の写真に対して付けられている、試料位置が未設定、または保存値が正しくない場合は、理由を表示して何も変更しません。すべての値を確認してから一度に置き換えるため、一部だけが変わることはありません。

引き継いだ後の設定は Scheduler 側で別に保存されます。どちらかで設定を変えても、もう一方には反映されません。

## ガスケット検出失敗時の復旧

ガスケット検出による追従では、指定した試料点を X 線位置に保ちます。試料点がガスケット中心から離れていると、補正後に輪郭が画角から欠け、検出できなくなることがあります。

通常の検出に成功している間は従来どおり動作します。**Average frames** による測定が検出失敗になった場合に限り、1 回の追従試行・位置合わせにつき 1 回、次の復旧を試します。

1. 「試料はほぼ X 線位置にある」と仮定し、登録した試料オフセットと較正から Ch4/Ch5 の移動量を求め、ガスケット中心を参照写真のガスケット中心位置へ近づけます。
2. ステージ停止後、必要なら参照位置付近でオートフォーカスし、新しい画像で再検出します。フレーム数と検出の信頼度基準は通常の追従と同じです。
3. 再検出できたら、実測したガスケット中心から試料位置を計算し、試料を X 線位置へ戻します。
4. Ch4/Ch5 の位置読戻しが移動指令と一致し、検出位置と実際の戻り移動から求めた推定残差が **Gasket tolerance** 内なら、その回の追従・位置合わせを成功とし、次の追従間隔または後続処理へ進みます。

X 線位置では輪郭が再び欠ける可能性があるため、戻った後の画像検証やオートフォーカスは行いません。復旧成功時のログは **inferred offset** と表示し、画像で直接確認した残差と区別します。IC の CSV では同じ残差列に推定値を記録します。

往復とも既存の 1 回あたり・開始位置からの移動上限とハードウェアの移動制約を適用します。通常のドリフト補正より大きな移動が必要な場合があり、上限によって参照位置へ届かなかったり、戻りの残差が許容値を超えたりすると復旧できません。上限を自動で拡大したり、移動を繰り返して迂回したりはしません。

再検出にも失敗した場合は、退避先でシーケンスをエラー停止します。自動で元の位置へは戻しません。通信異常、移動拒否、位置読戻しの不一致、ビーム・顕微鏡設定の不整合もエラーになります。停止要求後は次の往復動作を開始しません。

この復旧は継続追従、`stop_following()` 時の最終位置合わせ、`align_to_reference()` による単発位置合わせ、ルビー測定前の画像位置合わせに適用します。ルビー測定前は従来どおり Ch3 の登録位置への復帰を行い、復旧のためのオートフォーカスは追加しません。復旧後の推定残差を含めてガスケット中心基準のルビー移動先を計算します。初回試行を含め、検出失敗時に試料が X 線位置から大きく離れている場合は、復旧できないことがあります。
