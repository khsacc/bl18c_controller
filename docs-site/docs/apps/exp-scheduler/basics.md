# 自動測定の基本


## 実験の前に：自動測定を成功させるための３つのコツ

- ガスケットの穴は綺麗にする
  - ガスケットの穴を楕円として近似して画像認識します。穴が非対称だと追従に失敗する可能性が上がります。超音波洗浄などで穴を入念に綺麗にした方が良いです。
- ガスケットの穴径は300 µm以下にする
  - ガスケットの穴が大きすぎると、カメラの画角から穴のEdgeが外れてしまう結果として、試料位置の判定が難しくなります。
- 試料はできるだけ中心に置く
  - 試料がガスケットの中心から外れていても、X線回折測定は可能ですが、あまり端すぎると追従が不安定になりがちですので、できる限り中心付近に置くことを心がけてください。

## シーケンスの組み方

シーケンスの設定には二段階あります。ひとつは、それぞれのステップの設定、もうひとつは、Global settingsの設定です。

- 各ステップの設定には、ステップを並べるのに加えてFor文（ループ）も使用できます。今のところ、while文の使用は無限ループに陥る可能性を事前に検知するのが難しくなるので。ただし、For文では対応できないパターンもあるかもしれないので、よりよいシーケンスの組み方について、ご意見がありましたらお寄せいただければ幸いです。
- 画面の左側に表示されている設定群は、**Global settings**と呼ばれます。ここには、繰り返し登場する操作に関する設定項目を一括で設定するための入力欄が備えられています。Global settingsを適切に利用することで、各ステップで必要な設定値の入力を最小限に抑えることができます。
