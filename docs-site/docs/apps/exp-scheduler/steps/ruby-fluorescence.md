# Ruby Fluorescence

FluoRaPressée と連携して、ルビー蛍光スペクトルを測定するステップです。Global settings の **Ruby Fluorescence Settings** と、**Sample Positions** で登録したルビー位置を使います。

## take_spectrum

登録したルビー位置へステージを移動してルビー蛍光スペクトルを測定し、XRD 位置へ戻ります。

### 実行の流れ

1. 顕微鏡モードであることを確認します（XRD モードではエラー）。試料追従が動作中なら一時停止します。
1. 現在の Ch3（直前にオートフォーカスした場合はその合焦位置）を保持し、XRD 位置でカメラ画像をリファレンス画像と照合して Ch4/Ch5 のずれを補正します。セットアップ時の Ch3 への復帰や追加のオートフォーカスは行いません。
1. 補正後の位置に、登録したルビー位置の差分（Ch3/4/5）を加えた位置へ移動します。
1. Search timing が **Always** の場合は、近傍を探索し、最も強度の高い点へ移動します。
1. スペクトルを取得し、2 本のピークでフィットします。飽和した場合は露光時間を半分にして撮り直します。フィット失敗または R² が閾値を下回った場合は、条件付き近傍探索を設定していれば一度探索し、その後 EM Gain、積算回数の順に増やして撮り直します。上限まで試しても改善しなければエラーで停止します。
1. XRD 位置へ戻ります。

ルビー位置の Ch3 差分が 0 なら合焦位置を保持したまま移動し、0 以外なら現在の Ch3 にその差分を加えます。正常終了時は、画像位置合わせを始める前に保存した XRD 位置へ戻ります。

ガスケット方式の画像位置合わせで検出に失敗した場合は、試料がほぼ X 線位置にあると仮定し、参照位置付近へ退避して再検出する復旧を 1 回だけ試します。再検出できれば試料を X 線位置へ戻し、その推定残差を反映してルビー移動先を計算します。正常に検出できた場合の動作は変わりません。移動制限や再検出失敗時の停止については [ガスケット検出失敗時の復旧](../sample-tracking.md#ガスケット検出失敗時の復旧) を参照してください。

### 測定前の準備と Validation

`take_spectrum` は AF を行わず、正常終了時には画像補正前の開始座標へ戻ります。
**Align to reference（AF 有効）→ ルビー測定 → 顕微鏡 OUT / FPD IN → XRD**
の順序を推奨します。

Validation は、最後の圧力・温度設定変更や試料ステージ移動後に位置合わせ・AF が
確認できなければ Warning を表示します。AF 有効の追従も同等に扱い、待機や画像保存を
挟んでも準備状態は維持します。詳細は [Validationの内容](../validation.md) を参照してください。

### 設定項目

| 設定項目 | 内容 |
|---|---|
| Save full spectrum to file | スペクトルを実行フォルダの `spectrum/` に保存するか |
| Ruby position | 測定するルビー位置（登録済みの名前から選択） |
| Measure all registered ruby positions | チェックすると（既定）、登録したすべてのルビー位置を名前順に測定します。外すと Ruby position で選んだ 1 か所だけを測定します |
| Exposure time | 露光時間（0.01〜5 s）。**Use Global Settings** をチェックしたままなら Global settings の値を使います |
| Maximum EM Gain | 再測定時に上げる EM Gain の上限。同上 |
| Search best position nearby | チェックすると、ルビー位置の周囲を格子状に探索し、最も強度の高い点で測定します |
| Use Global Settings for nearby search | チェックしたままなら、探索条件は Global settings の値を使います |
| Search timing | **Always**：毎回探索します。**If initial fit fails or R² is below threshold**：まずルビー位置で測定し、フィット失敗または R² が閾値を下回った場合だけ一度探索します |
| Ch3/Ch4/Ch5 full range | 探索に使う軸、探索範囲（全幅、µm）と刻み幅（パルス数） |

### 探索した位置の引き継ぎ

近傍探索後の最終スペクトルが品質基準を通過すると、その位置を**同じシーケンス実行中の次回以降の初期位置**として使います。位置はルビー名ごとに保持し、通常測定、全ルビー測定、ループ、ルビーを使う加圧・減圧操作の間で共有します。次のステップで探索を無効にしていても、更新後の位置へ移動します。

保持するのは、登録時と同じ基準からの Ch3/4/5 相対位置です。例えば穴中心から +20 パルスで登録し、探索で予定位置より +3 パルスの点を採用した場合、次回はその時点の穴中心から +23 パルスを使います。毎回の画像位置合わせは従来どおり行います。

測定失敗、停止、無効な圧力結果では位置を更新しません。温度補正の適用範囲外という警告だけの場合は、スペクトルの品質基準を通過していれば更新します。更新した位置と探索範囲も移動前にリミットを確認し、変更内容を `<Run name>_ops.log` に記録します。

引き継ぎは実行中だけ有効です。登録位置や保存済みシーケンスは変更せず、次に Run を開始すると登録位置から再開します。


### 圧力が規定値に達したら停止する

Ruby Fluorescence Settings の **Pressure Calculation** を有効にしている場合、次の設定が使えます。

| 設定項目 | 内容 |
|---|---|
| Stop sequence when ruby pressure reaches target | チェックすると、ルビー圧が目標に達した時点でシーケンスを終了します |
| Target pressure | 目標圧力（GPa） |
| Tolerance | 許容幅（GPa）。「目標 − 許容幅」以上の有効なルビー圧が得られたら終了します |

PACE5000 で段階的に加圧しながらルビー圧を測るループで、目標圧力に達したら止める、という使い方を想定しています。条件を満たすと、シーケンスはルビー位置で終了します（XRD 位置へは戻りません）。PACE5000 は最後の設定圧のまま Control モードで残るので、その後の圧力の扱いは利用者が判断してください。また、ルビー圧は測定のたびにしか分からないため、ちょうど目標圧で止まる保証はありません。

ルビー圧を目標にして自動で加圧・減圧したい場合は、PACE5000 の [compress_to_target_pressure_using_ruby](pace5000.md#compress_to_target_pressure_using_ruby) を使ってください。現在の試料圧から一定量だけ加圧・減圧したい場合は [compress_by_relative_pressure_using_ruby](pace5000.md#compress_by_relative_pressure_using_ruby) を使ってください。

保存名は `<Run name>_spectrum_<Ruby name>_<suffix…>_attempt_NN` です。Ruby name には **Set up sample positions…** の登録名を使います。禁止文字の置換と長い名前の短縮については[出力ファイル](../output-files.md)を参照してください。
