# PACE5000

Druck PACE5000 でガス圧を制御するステップです。

## set_and_wait_pressure

ガス圧の目標値と昇降圧速度を設定し、目標圧に到達するまで待ってから次のステップへ進みます。set_pressure と wait_pressure を 1 ステップにまとめたもので、通常はこちらを使います。

| 設定項目 | 内容 |
|---|---|
| Pressure | 目標圧。For ループ内ではループ変数も使えます |
| Unit (pressure & tol) | 目標圧と許容幅の単位（MPa / Bar） |
| Rate / Rate unit | 昇降圧速度（MPa/min / Bar/min） |
| Tolerance | 到達とみなす許容幅 |

測定値が「目標 ± 許容幅」に入り、そのまま一定時間（2 秒）保たれたら到達とみなします。

## set_pressure

ガス圧の目標値と昇降圧速度を設定し、**到達を待たずに** 次のステップへ進みます。速度を設定してから目標圧を送り、それぞれ装置の読み戻しで反映されたことを確認します。

| 設定項目 | 内容 |
|---|---|
| Pressure | 目標圧。For ループ内ではループ変数も使えます |
| Unit | MPa / Bar |
| Rate / Rate unit | 昇降圧速度 |

昇圧中に別の操作を並行して進めたいときに使います。

## wait_pressure

PACE5000 に設定されている目標圧に到達するまで待ちます。

| 設定項目 | 内容 |
|---|---|
| Tolerance | 到達とみなす許容幅 |
| Unit | MPa / Bar |

判定の方法は set_and_wait_pressure と同じです。

## set_control_mode

PACE5000 の動作モードを切り替えます。

| 設定項目 | 内容 |
|---|---|
| Mode | **Control**：設定圧に向けて圧力を制御します。**Measure**：圧力の制御をやめ、測定だけを行います |

## compress_to_target_pressure_using_ruby

ルビー圧が目標の **試料圧** に達するまで、ガス圧を少しずつ上げていきます。

### 実行の流れ

1. ガス圧が現在の設定圧で安定するのを待ち、ルビー圧を測定します。すでに目標以上なら、ガス圧を変えずにステップを終了します。
1. ガス圧を **Gas pressure increment** だけ上げ、到達して安定するまで待ちます。
1. **Pressure stabilisation duration** だけ待ちます。
1. XRD 位置に戻って画像で位置を合わせ直し、同じルビーを測定します。
1. ルビー圧が目標に達するまで 2〜4 を繰り返します。達したら XRD 位置へ戻ってステップを終了します。

ガス圧が上限（Max allowed gas pressure）に達しても目標に届かない場合は、XRD 位置へ戻ってからエラーで終了します。成功・失敗にかかわらず、PACE5000 は最後の設定圧のまま Control モードで残ります。

### 前提条件

- 顕微鏡モードであること
- PACE5000 が Control モードであること
- Ruby Fluorescence Settings の **Pressure Calculation** が有効であること
- ルビー位置を 1 か所選んでいること

### 設定項目

ルビー測定に関する項目（保存、露光時間、Maximum EM Gain、近傍探索など）は [take_spectrum](ruby-fluorescence.md#take_spectrum) と共通です。このステップ固有の項目は次のとおりです。

| 設定項目 | 内容 |
|---|---|
| Target sample pressure | 目標の試料圧（GPa）。For ループ内ではループ変数も使えます |
| Gas pressure increment | 1 回あたりのガス圧の増分 |
| Gas pressure unit | MPa / Bar |
| Pressure stabilisation duration | ガス圧到達後、ルビー測定までの待ち時間（s） |
| Max allowed gas pressure | ガス圧の上限。PACE5000 の供給圧より低い値にする必要があります |
| Use current PACE5000 slew rate | チェックしたままなら現在の昇降圧速度を使います。外すと **Gas pressure rate** で指定できます |
| Arrival tolerance | ガス圧の到達とみなす許容幅 |

:::warning

ガス圧の到達待ちにはタイムアウトがありません。圧力が設定値に届かない状況では、Stop を押すまで待ち続けます。

:::

## decompress_to_target_pressure_using_ruby

ルビー圧が目標の試料圧 **以下** になるまで、ガス圧を少しずつ下げていきます。動作と設定項目は compress_to_target_pressure_using_ruby と同じで、次の点が異なります。

- **Gas pressure increment** だけガス圧を下げていきます。
- ガス圧の上限の代わりに **Min allowed gas pressure**（下限、0 も可）を指定します。下限に達しても目標に届かない場合はエラーで終了します。
