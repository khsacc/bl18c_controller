# 自動測定の開始・終了

シーケンス実行中は、左側の **Global settings** 全体が入力・変更できなくなります。Global Limits、Positions、Logging、XRD、シャッター、Sample Positions、Ruby Fluorescence の設定と、ファイル選択・位置登録などのボタンが対象です。設定内容はスクロールして確認できます。

**Stop** または **Emergency Stop** を押した後も、実行スレッドの終了と後片付けが完了するまで設定は変更できません。終了後にシャッターを元の位置へ戻す場合は、その処理の完了後に編集可能になります。開始に失敗した場合もロックを解除します。

Run Monitor の表示や Stop / Emergency Stop は引き続き使用できます。
