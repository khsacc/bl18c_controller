# FPD (Rad-icon 2022)

X線フラットパネル検出器（Teledyne, Rad-icon 2022）を制御するアプリケーションです。

![](/img/apps/xrd/FPD_control.png)

## 露光時間
- 秒単位で指定します。
- BL-18CのFPDでは、X軸をflipするとこれまでの商用ソフトウェアの挙動に合います。

## 保存設定

- 保存先と、ファイル名を選択します。



## Dark補正
- 露光時間が同一のファイルでないとエラーを吐きます。
- まだ測定していない場合「Acquire」から測定します。測定が修了すると保存先を選ぶウィンドウが自動で開きます。


## 画素欠陥補正設定

- 起動時に前回の欠陥ファイル（なければ付属ファイル）を読み込みます。別のファイルは **Browse...** から選択できます。
- **None** は補正なし、**median** は欠陥画素を周囲の正常画素の中央値で置換します。近傍サイズは 3×3～6×6 から選べます。
- **Replace with -1** は欠陥画素を `-1` に置換します。16 ビット画像では `65535` として記録されます。CrysAlisProでの解析において、自動でデータなしピクセルと判定されます。

## 露光
- Live表示（データは保存しないが露光は行う）、単発露光、連続露光が可能です。

## Instant 1D reduction (XRD)

- チェックを入れると、登録済みの PONI ファイルを使い、補正後の画像を pyFAI で 1 次元化して 2θ–強度プロファイルを表示します。積分にはピクセル分割、立体角補正、偏光係数 0.95 を使用します。
- 角度分解能の初期値は **0.01°/bin**。2θ の下限・上限は **Auto** で検出器の全範囲となり、必要に応じて指定できます。
- **Find spots before 1D integration** を有効にすると、検出したスポットを積分から除外します。閾値は **Settings → XRD analysis** で設定し、保存する補正済み TIFF は変わりません。
- **Auto-save 1D data** では、選択した形式（CSV、TSV、GSAS、Z-Rietveld）で TIFF と同じ場所に保存します。CSV/TSV は 2θ・Q・d の出力軸を選べます。
