# XRD 1D reduction

保存済みの2D XRD TIFF画像を、検出器への接続なしで1次元化するアプリです。ランチャーの XRD 欄から開きます。単独起動は `python -m apps.xrd_1d_reduction.reduction_app` です。

1. **Open 2D image…** でグレースケールの `.tif` / `.tiff` を選ぶか、TIFFファイルを1つウィンドウへドラッグ＆ドロップします。画像上やグラフ上にもドロップできます。
2. **Detector settings** で PONI 較正を登録します。登録済みならランチャーと共有します。**Calibrate detector geometry** から既存の較正アプリも開けます。
3. 必要なら画像上でマスクを編集します。**Rectangle**／**Circle** を選び、左ドラッグで追加、右ドラッグで解除します。ドラッグ中は輪郭を表示します。
4. 画像下の2θ–強度グラフに結果が表示されます。**Save 1D data** で画像と同じフォルダーへ保存できます。

**Mask Spots** は現在の画像に対してスポットを検出し、積分対象から除外します。閾値は **Settings → XRD analysis** と共通です。ダイヤモンド厚さ補正も同じ設定を使い、どちらの画面から変更しても即時に反映されます。元のTIFFは変更しません。

スポットマスクと手動マスクには、次の画像を開いた時の扱いをそれぞれ指定できます。**Keep masked spots / Keep current mask** は画像寸法が同じ場合に現在のマスクを引き継ぎます。**Keep mask file** は最後に読み込んだ、または保存したファイルを再適用します。**Do not keep mask** は消去します。マスクは寸法を保存できる `.npz` と IPAnalyzer の `.mas` を読み書きできます。`.mas` には画像の縦横寸法が記録されないため、異なる画像へ適用する際は画素数を確認してください。

保存済みマスクを自動で再適用した場合、そのファイル名を画像情報と状態表示に示します。スポット検出では、既存の手動・スポットマスクをリング統計から除外します。検出中に左ドラッグでマスクを追加したり、2θ範囲・閾値・ジオメトリを変更したりした場合は、現在の条件で再検出します。**Clear mask** または右ドラッグでマスクを解除した場合は、待機中のスポット検出を取り消し、実行中の検出結果も適用しません。その直後にマスクや設定を変更しても、取り消した検出は再開しません。再検出する場合は **Mask Spots** を押します。取消は状態欄と次の積分結果に表示し、その後の結果には残しません。

積分には Rad-icon の **Instant 1D reduction** と同じ共通処理を使います。角度分解能、2θ範囲、CSV／TSV／GSAS／Z-Rietveld 保存形式と軸単位を選べます。自動保存と PDIndexer 自動送信は画像を開いた直後の結果にだけ適用されます。マスクや設定の変更後は **Save 1D data**／**Send now to PDIndexer** を使います。どちらも初期設定はオフです。

最初の結果が出る前にマスクや積分設定を変更すると、有効になっている自動保存・自動送信は省かれ、その理由を状態欄に示します。両方ともオフの場合は省略通知を表示しません。スポット閾値だけの変更では積分をやり直しません。保存と送信を両方選んだ場合、保存エラーを含めて両方の結果を状態欄に表示します。
