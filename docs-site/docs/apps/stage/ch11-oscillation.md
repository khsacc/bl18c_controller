# DAC stage oscillation

メインウィンドウのボタン：**DAC stage oscillation**

Ch11 を用いて、試料の揺動を行うためのアプリケーションです。

![DAC Stage Oscillation のスクリーンショット](/img/apps/stage/dac_oscillation.png)

## 機能紹介

- **Pos A** および **Pos B** として入力した位置の間を往復します。**Unit** を切り替えることで、値をパルス値でも角度でも入力できます。
- **Dwell** は、Pos A ならびに Pos B における待機時間です。ただし実機では、通信や、ステージが完全に停止したことの確認に時間がかかるため、これを 0 ms に設定しても、すぐに折り返し動作が始まるわけではありません。1 秒未満ではありますが、わずかな遅延が生じます。したがって、この値にはあまり定量性がないと考えてください。
- **Cycles** を設定すると、指定した回数の往復が完了した時点で動作が停止します（0 に設定すると、停止するまで往復を続けます）。

:::warning[重要]
Ch11 には、衝突を回避するためのソフトウェアリミッターが実装されていません。これは、ステージ上に設置しているセル関係の部品によって、回転可能な範囲が容易に変化するためです。本機能を利用する前には、かならず指定した範囲で手動の回転テストを行い、ステージが衝突しないことを確認してください。
:::
