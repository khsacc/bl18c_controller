# PACE5000

メインウィンドウのボタン：**PACE5000**

メンブレン駆動 DAC の圧力制御に用いるガス圧コントローラ Druck PACE5000 を制御するためのアプリケーション "PaceMaker" です。メイン画面およびスケジュール制御画面の二つの画面からなります。

## メイン画面

![PACE5000 メイン画面のスクリーンショット](/img/apps/sample-environment/screenshot_main.jpg)

- **Mode**：ガス圧を制御するか、制御せずにモニターだけを行うかを選択します。ラジオボタンの選択は即時に反映されます。
- **Pressure Unit**：PACE5000 は MPa および bar に対応しており、これらを切り替えられます。
- **Target Pressure**：設定圧力です。Enter キーを押すまでは反映されません。本アプリケーションは、ガスボンベから供給される圧力（+ve source）を常時モニターしており、+ve source の圧力よりも高い値が設定された場合は、警告を出して操作をブロックします。
- **Slew Rate**：ガス圧を変更するときの速度です。Enter キーを押すまでは反映されません。時間の単位として sec および min を選択できます。制御可能な最低速度は 0.0001 MPa/sec で、これは時間および圧力の単位に依存しません。これより遅い速度が設定された場合は、警告を出して操作をブロックします。
- **Confirm before apply**：チェックすると、Enter キーを押したときに、圧力や速度を本当に変更するかを確認するポップアップが開きます。誤ったキー操作で設定値が変わるのを防げます。
- **Relative pressure change**：現在値からの相対値で Target Pressure を変更します。変更は即時に反映されます。
- **Data Logging**：ログデータを CSV 形式で保存します。

## スケジュール制御画面

![PACE5000 スケジュール制御画面のスクリーンショット](/img/apps/sample-environment/screenshot_schedule.jpg)

事前に設定したパターンに沿って圧力を上下させる機能です。**Change Pressure** および **Wait** に対応しています。
