# 共通設定

メインウィンドウのメニューバーから **Settings → Settings…** を選ぶと、複数のアプリで共有される設定をまとめた Settings ウィンドウが開きます。左側のリストで項目を選ぶと、右側にその設定ページが表示されます。

設定値は、特に断りのない限り制御 PC の `settings/__localdata/` に保存され、次回起動時にも引き継がれます。
